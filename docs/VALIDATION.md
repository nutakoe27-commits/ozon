# Проверка первой версии

Базовая версия проверена 20 октября 2026 года в облачной среде разработки. На реальном VPS SpaceWeb проверки из этого документа не выполнялись.

27 октября 2026 года доработки редактирования курсов и конструктора прошли 30 серверных и 8 браузерных тестов, проверку TypeScript и production-сборку. Проверены редактирование опубликованного начатого курса с сохранением результатов, добавление и удаление уроков, несколько безопасных зон, настройка и восстановление начальной позиции, совместимость прежних заданий, загрузка видео и фотографии из формы теста, порядок материалов и отсутствие автоматического зачёта теста за просмотр видео. Контейнерная конфигурация и структура таблиц для этих доработок не менялись. После добавления вопросов с несколькими правильными ответами прошли 33 серверных и 9 браузерных тестов, TypeScript и сборка. Проверены смешанные типы вопросов, совместимость прежних вопросов, приватность ключей ответов, точное совпадение выбранного набора, отказ при неполном наборе и лишних вариантах, перенос отметок при удалении варианта, повторные попытки, однократное начисление баллов и выдача сертификата. Таблица ниже относится к проверке базовой версии.

Интеграционные проверки охватывают авторизацию, CSRF/Origin, разграничение ролей, отсутствие ответов и целевой зоны в API ученика, создание/публикацию/назначение курсов, оценку заданий, однократное начисление XP, выдачу и доступ к сертификату, запрет изменения начатой программы, загрузку по частям и возобновление, работу FFmpeg, приватный HLS и HTTP Range, учёт просмотра, неверный контейнер, безопасное удаление материалов, отмену загрузок, перекодирование изображений, CSV и отзыв сессий при сбросе пароля.

Браузерные сценарии: кабинет и поиск курсов; создание курса и прохождение теста/сцены до сертификата; фактическое воспроизведение HLS и изменение скорости; мобильная навигация без горизонтального переполнения; загрузка файла через интерфейс до готовности обработанного материала.

Отдельно проверен production-образ через настоящий HTTP API и отдельную Compose-базу: bootstrap администратора, Secure-cookie, CSP, загрузка видео, отдельный worker, три типа уроков, прогресс, XP и сертификат. В проверке восстановления данные намеренно изменили после backup и подтвердили возврат исходного состояния вместе с видео.

Не проверены: публичный DNS и выдача HTTPS для learn.krichiginmo.ru, нагрузка на конкретном VPS, загрузка файла 10 ГиБ через реальную сеть пользователя, восстановление снимка облачной среды в новой задаче, результат удалённого GitHub Actions. Эти проверки не подменяются локальными тестами. Workflow CI добавлен в `.github/workflows/ci.yml`.
